# Campaign Wiki Content Rules

When creating or updating campaign-wiki entries under `content/`:

- Include only information explicitly provided by the user.
- Do not invent, embellish, expand, or infer lore, descriptions, motivations, relationships, history, or other facts.
- Edit the user's wording only as needed for grammar, clarity, and proper sentence structure while preserving the intended meaning.
- Add Obsidian-style `[[wikilinks]]` only when the target is an existing wiki note or an existing generated folder page.
- Verify that a target exists before linking to it. Do not create speculative or placeholder links for subjects that may receive entries later.
- Link only setting-specific subjects that help readers navigate between related entries. Do not link generic terms merely because they could become notes.
- Do not link an entry to itself.
- Prefer fewer useful links over many low-value links.
- Do not add links that change the meaning of the supplied information.
- Preserve the user's names, terminology, tone, and factual distinctions.
- If information is ambiguous or seems contradictory, ask the user rather than resolving it through invention.
